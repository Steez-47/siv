## Design system: Steez
All UI in this repo uses the Steez design system. Before any front-end work, read `DESIGN.md`.
Copy components from `steez/library.html` (numbered `STZ x.y.zz`). Do not invent new ones.
Every page includes `steez/css/steez.css` and `steez/js/steez.js` in `<head>`.
